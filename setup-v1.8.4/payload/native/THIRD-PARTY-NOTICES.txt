sources, applied dependency-port patches and build instructions are supplied in
native-source.zip. No separate proprietary game code is contained in the helper.

The automatically launched TavernMeshPeer.exe is GPL-3.0-or-later. Its source and
build instructions are in mesh-peer-source.zip; see MESH-PEER-LICENSE.txt.
Newtonsoft.Json is MIT licensed; see NEWTONSOFT-LICENSE.txt.

Bootstrap seed addresses are from https://nodes.tox.chat/json. They are discovery
points and public TCP connection helpers, not a shared Tavern friends database.
See seed-provenance.json for the bundled snapshot. Availability can change.

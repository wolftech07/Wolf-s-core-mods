`tavern-badge.png` is a lossless PNG conversion of the unchanged 32×32 T icon embedded in the user-supplied Tavern Launcher 1.8.3 `icon_data.py` ICO. Its design and pixels were not edited. The launcher banner is not bundled or modified.

`tavern-badge-hires.png` is a separate 1254×1254 RGBA reconstruction generated with the built-in image-generation tool from that icon. It preserves the red circular medallion, silver rim, and serif T design, but is not an official high-resolution original. The background outside the circle is transparent. This version is embedded as `TavernNativeMenu.Badge.png` by Build-Mod.ps1. The original `tavern-badge.png` is retained unchanged.
